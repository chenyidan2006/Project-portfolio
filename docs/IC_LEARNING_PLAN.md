# 数字 IC 实践计划

状态：建议方案，尚未实施。当前仅确认本学期开始学习 Verilog / SystemVerilog 与 FPGA。

## 第一个项目建议

做 UART RX + 同步 FIFO。它与已有串口通信经历相连，适合练习时序逻辑、状态机、位宽、边界条件和验证方法。首版使用单时钟，UART 输入需先处理外部异步输入；采样策略与同步器设计应在规格中说明。未选定开发板前不填写引脚和时钟值。

| 阶段 | 交付 | 验收条件 |
| --- | --- | --- |
| 规格 | 时钟/波特率、8N1格式、复位、FIFO深度、满空与错误行为 | 所有输入输出和异常行为有明确定义 |
| UART RX | RTL、独立 testbench、波形 | 正常帧、连续帧、错误停止位、复位打断均有自动检查 |
| 同步 FIFO | 参数化RTL与参考队列记分板 | 满、空、同时读写、指针回绕行为符合规格 |
| 集成仿真 | 串行输入到FIFO输出的端到端检查 | 测试结果可自动判定，失败能定位 |
| 综合 | 工具版本、时钟约束、时序和资源报告 | 报告可重现，无未解释的时序或锁存器问题 |
| FPGA | 引脚约束、运行步骤、抓波或回环记录 | 目标板上按约定规格完成实验 |

后续再考虑 ready/valid、APB寄存器或异步FIFO，避免首版范围过大。完成一个阶段才更新对应状态；仿真通过、综合通过和上板通过分别记录。
