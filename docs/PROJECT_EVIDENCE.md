# 项目证据与验证范围

本说明区分个人分工、团队实现、代码静态检查与尚未验证的结论。2026-10-16 整理。未发布原始项目目录、完整报告、模型、私人联系方式或实验人员数据。

## SMI

- 个人工作：App 全部前后端、ESP32 到服务器通信、算法重训练与优化；依据原项目详情和既有项目说明，未重新验证线上服务。
- 光学原理、传感方案、采集硬件属于团队研究，不表述为个人芯片设计。
- 本轮保留既有核对口径：连续单通道 40 kHz、16 bit；UART 1,152,000 baud；8 秒为 320,000 点、640,000 字节原始负载。帧头 ch=2 不证明有两个物理采集通道。
- 40 kHz 降到 20 kHz 后，完整记录仍为 8 秒；现役适配器取前 100,000 点作为 5 秒输入。
- 原始数据带宽为 80,000 字节/秒。假设 UART 采用 8N1，1,152,000 baud 的理论字节上限为 115,200 字节/秒；8 秒负载纯串口传输至少约 5.56 秒，未计协议与处理开销。持续运行还需检验缓存、实际吞吐与丢包情况。
- 本轮没有重新运行采集固件、服务器或模型，不能据此新增准确率、实时性或医学有效性结论。

### 静态可解析性与复现范围

用Python AST检查10个国赛快照Python文件：8个可解析；7.13与市赛结束的velpub51.py均在第417行出现TabError。此检查不执行代码、不加载GPU、不驱动车辆；可解析也不等于可运行。原始档案未修改。

独立国赛快照没有包含全部utils111.inference/data、模型及ROS启动依赖；较大的重要代码目录另有部分依赖，需确认对应版本才能组装。尚无最终比赛镜像与硬件验证，不将任何一个快照称为最终可复现版本。

### 不采用的结论

目前代码材料不足以支持训练策略优化、剪枝、量化提效、训练精度、实时FPS或独立开发所有模块等结论。50 Hz为控制循环配置；目录“30%满分率”不是统计日志；定时动作不是路径规划器。
